## 概要

**Codex MCP**は、OpenAIのCodex CLIをMCPサーバーとして利用するツールである。
Claude Codeから直接Codex（GPT-5.3-codex等）を呼び出し、コーディング支援やコードレビューを実行できる。

### 主な特徴

- **非対話モード実行**: プロンプトを渡してAIコーディング支援を受ける
- **コードレビュー**: Git差分に対する自動レビュー
- **セッション管理**: 会話を継続して文脈を保持
- **サンドボックス**: 安全な実行環境を提供

## ツール一覧

### 1. mcp__codex__codex（メイン機能）

非対話モードでAIコーディング支援を実行する。

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `prompt` | ✅ | タスク・質問・分析リクエスト |
| `model` | - | 使用モデル（デフォルト: gpt-5.3-codex） |
| `fullAuto` | - | サンドボックス自動実行モード |
| `sandbox` | - | read-only / workspace-write / danger-full-access |
| `sessionId` | - | 会話継続用セッションID |
| `workingDirectory` | - | 作業ディレクトリ |
| `reasoningEffort` | - | 推論深度（none/minimal/low/medium/high/xhigh） |

#### 利用可能なモデル

| モデル | 説明 |
|--------|------|
| gpt-5.3-codex | 最新・最高性能（デフォルト） |
| gpt-5.2-codex | 安定版 |
| gpt-5.1-codex | 軽量版 |
| gpt-5.1-codex-max | 拡張版 |
| gpt-5-codex | 標準版 |
| gpt-4o | GPT-4o |
| o3 | 推論特化モデル |
| o4-mini | 軽量推論モデル |

### 2. mcp__codex__review（コードレビュー）

Gitリポジトリに対するコードレビューを実行する。

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `base` | - | ベースブランチ（例: "main"） |
| `commit` | - | 特定コミットSHAのレビュー |
| `uncommitted` | - | 未コミット変更のレビュー（true/false） |
| `prompt` | - | カスタムレビュー指示 |
| `model` | - | 使用モデル |
| `workingDirectory` | - | 作業ディレクトリ |

### 3. mcp__codex__ping（接続テスト）

MCPサーバーの接続確認。

```
mcp__codex__ping(message: "テストメッセージ")
→ メッセージがエコーバックされれば正常
```

### 4. mcp__codex__listSessions（セッション一覧）

アクティブな会話セッションの一覧を表示。

### 5. mcp__codex__help（ヘルプ）

Codex CLIのヘルプ情報を表示。

## 基本的な使用例

### 例1: コード生成

```
mcp__codex__codex(
  prompt: "TypeScriptでユーザー認証のユーティリティ関数を作成せよ",
  model: "gpt-5.3-codex"
)
```

### 例2: コード分析

```
mcp__codex__codex(
  prompt: "このコードのパフォーマンス問題を分析せよ: [コード]",
  reasoningEffort: "high"
)
```

### 例3: 未コミット変更のレビュー

```
mcp__codex__review(
  uncommitted: true,
  prompt: "セキュリティの観点からレビューせよ"
)
```

### 例4: ブランチ間のレビュー

```
mcp__codex__review(
  base: "main",
  prompt: "コード品質とベストプラクティスの観点からレビューせよ"
)
```

### 例5: セッション継続

```
# 初回
mcp__codex__codex(
  prompt: "Reactコンポーネントの設計を相談したい",
  sessionId: "session-001"
)

# 継続
mcp__codex__codex(
  prompt: "そのコンポーネントにテストを追加せよ",
  sessionId: "session-001"
)
```

## サンドボックス設定

| 設定 | 説明 | 推奨用途 |
|------|------|----------|
| `read-only` | 読み取り専用（デフォルト推奨） | 分析・調査 |
| `workspace-write` | ワークスペース内のみ書き込み可 | コード生成・修正 |
| `danger-full-access` | 全アクセス（危険） | 信頼できる環境のみ |

### ⚠️ 注意事項

1. **デフォルトは `read-only` を推奨** - 不用意なファイル変更を防ぐ
2. **`fullAuto` は慎重に使用** - 自動実行は予期せぬ動作の可能性あり
3. **`danger-full-access` は原則禁止** - 明示的な許可がある場合のみ

## 🔴 コードレビュー運用フロー（殿の方針）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  足軽1-6   │ ──→ │  足軽7-8   │ ──→ │   軍師     │
│ コード作成  │     │ Codexレビュー │     │  報告受領   │
└─────────────┘     └─────────────┘     └─────────────┘
     │                    │
     │                    ▼
     │           mcp__codex__review
     │           でレビュー実行
     │
     ▼
  セルフレビュー可
  （提出前チェック）
```

### フロー詳細

1. **足軽1-6**: タスクに従いコードを作成
   - 必要に応じてセルフレビュー（Codex使用可）
   - 完了後、報告書を作成

2. **足軽7-8**: 足軽1-6の成果物をCodexでレビュー
   - `mcp__codex__review` を使用
   - 問題点・改善点を報告

3. **軍師**: レビュー結果を集約し家老に報告

### 足軽7-8用レビュー例

#### 例1: 未コミット変更のレビュー

```
mcp__codex__review(
  uncommitted: true,
  workingDirectory: "/home/nishimura/arms-mock/frontend",
  prompt: "以下の観点でレビューせよ: 1)バグの有無 2)コード品質 3)セキュリティ"
)
```

#### 例2: 特定コミットのレビュー

```
mcp__codex__review(
  commit: "abc1234",
  workingDirectory: "/home/nishimura/arms-mock/backend",
  prompt: "NestJSのベストプラクティスに従っているか確認せよ"
)
```

#### 例3: mainブランチとの差分レビュー

```
mcp__codex__review(
  base: "main",
  workingDirectory: "/home/nishimura/arms-mock",
  prompt: "以下を確認せよ: 1)TypeScript型安全性 2)React警告の有無 3)未使用コード"
)
```

#### 例4: セキュリティ重点レビュー

```
mcp__codex__review(
  uncommitted: true,
  prompt: "セキュリティ観点で徹底レビューせよ: SQLインジェクション、XSS、認証漏れ、機密情報露出"
)
```

## セッション管理

### セッションIDの活用

長い会話や複数ステップのタスクでは `sessionId` を使用して文脈を保持する。

```
# ステップ1: 設計相談
mcp__codex__codex(
  prompt: "ユーザー管理機能の設計を相談したい",
  sessionId: "user-management-design"
)

# ステップ2: 実装
mcp__codex__codex(
  prompt: "先ほどの設計に基づいてCRUD APIを実装せよ",
  sessionId: "user-management-design"
)

# ステップ3: テスト
mcp__codex__codex(
  prompt: "実装したAPIのテストコードを作成せよ",
  sessionId: "user-management-design"
)
```

### セッション一覧確認

```
mcp__codex__listSessions()
```

## ベストプラクティス

1. **具体的なプロンプト** - 曖昧な指示は避け、具体的に記載
2. **適切なモデル選択** - 簡単なタスクは軽量モデル、複雑なタスクは高性能モデル
3. **サンドボックス遵守** - 必要最小限の権限で実行
4. **セッション活用** - 関連タスクは同一セッションで継続
5. **結果の検証** - Codexの出力は必ず検証してから使用
