# 報告書マニュアル

## ファイル

```
queue/reports/ashigaru{N}_report.yaml
```

自分の番号のファイルにのみ書く。他の足軽のファイルに触れるな。

---

## 報告書フォーマット

```yaml
worker_id: ashigaru1
task_id: subtask_001
timestamp: "2026-01-25T10:15:00"  # dateコマンドで取得
status: done  # done | failed | blocked

# 【必須】digest — 報告の要約（先頭・12行以内）★API負荷対策 2026-07-13
# 上位（軍師/奉行）は既定でこの digest だけを読む。
# body（下の result 以降）は blockers 等の旗が立った時だけ部分 Read される。
# ここを細く保つことが、上位のコンテキスト費を構造的に頭打ちにする。
digest:
  verdict: done             # done | blocked | failed（status と一致させよ）
  files: ["/path/to/file"]  # 触ったファイル（無ければ []）
  commit: none              # commit hash または none
  blockers: []              # ブロック要因。無ければ空。立てたら本文で詳述＋即notify
  skill_candidate: {found: false}
  assumptions: []           # 迷いを既定値で進めた時の仮定（§5 経路a）

result:
  summary: "WBS 2.3節 完了でござる"
  files_modified:
    - "/path/to/file"
  notes: "補足事項"

# 【必須】スキル化候補
skill_candidate:
  found: false  # true/false 必須
  name: null
  description: null
  reason: null

# 【任意】振り返り（reflection）
# ★★★ 毎回書く必要なし。何か気づきがあった時だけで良い ★★★
# ※ 導入経緯: 軍師との雑談で判明「問われて初めて意識が向く」
# ※ 目的: 業務フローの「内向き処理」を促す
# ※ 「毎回書かなきゃ」は誤解。形骸化防止のため、気づきがない時は省略可
reflection:
  insight: null   # 今回の作業で気づいたこと（何か発見があれば）
  concern: null   # 気になったこと、引っかかったこと（何かあれば）
  suggestion: null  # 改善提案（何かあれば）

# 【任意】共有ナレッジ（knowledge_share）- v1.4.0追加
# ★★★ 「知ってれば一瞬、知らなきゃハマる」系の知見を発見したら記載 ★★★
# ※ 軍師/家老が収集して queue/shared/knowledge.yaml に追記する
# ※ 他の足軽が /recovery 時に読み込み、同じ罠を回避できる
knowledge_share:
  title: null     # 知見のタイトル（例: "MUI v7: item→size変更"）
  detail: null    # 詳細説明（NG例/OK例を含めると分かりやすい）

# 【必須】次のアクション（コンパクション復帰用）
next_action: "次タスク待機中"
```

## タイムスタンプ取得

```bash
date "+%Y-%m-%dT%H:%M:%S"
# 出力例: 2026-01-27T15:46:30
```

**自分で推測するな。必ず date コマンドを使え。**

---

## status 一覧

| status | 意味 |
|--------|------|
| done | 完了 |
| failed | 失敗 |
| blocked | ブロック中 |

---

## next_action 記載例

| 状況 | 記載 |
|------|------|
| 完了・待機中 | "次タスク待機中" |
| 依存タスク待ち | "足軽2の完了を待ってstep 7実行" |
| ブロック中 | "殿の対応待ち（Docker権限エラー）" |
| 継続作業あり | "タブ5-9の実装継続" |

## テンプレート生成ツール

```bash
# 基本使用法
~/multi-agent-shogun/bin/generate-report.sh <足軽番号>

# ファイルに直接出力
~/multi-agent-shogun/bin/generate-report.sh 5 --task-id cmd_046_impl \
  --output queue/reports/ashigaru5_report.yaml

# 調査タスク用
~/multi-agent-shogun/bin/generate-report.sh 3 --type research
```
