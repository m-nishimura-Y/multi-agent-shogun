# 永続化マニュアル

> 「永続化なき作業は、砂上の楼閣なり」

---

## なぜ永続化が必要か

- コンパクション後、会話履歴は要約される
- 要約から漏れた情報は失われる
- **報告書** と **next_action** が復帰時の手がかりになる

---

## 足軽が意識するファイル

| ファイル | 用途 | 更新タイミング |
|----------|------|----------------|
| queue/reports/ashigaru{N}_report.yaml | 自分の報告書 | タスク完了時 |
| queue/progress.yaml | 進捗状況 | タスク開始・完了時 |

---

## 報告書への next_action 記載（必須）

**コンパクション復帰時に何をすべきか分かるように記載せよ。**

```yaml
# タスク完了時
next_action: "次タスク待機中"

# ブロック時
next_action: "家老/奉行からの判断待ち（XXXの件）"

# 作業継続中
next_action: "XXX機能の実装継続（残り：YYY）"
```

---

## 報告書の必須項目

```yaml
report:
  task_id: subtask_XXX
  status: done | failed | blocked
  summary: "何をしたか"

  skill_candidate:
    found: true | false  # ★必須（false でも記載）

  next_action: "次タスク待機中"  # ★必須

  # 開発タスクの場合
  build_check:
    fe: success | fail | skip
    be: success | fail | skip
```

**skill_candidate と next_action は必須。** 抜けていると差し戻される。

---

## 進捗更新（progress.yaml）

```bash
# タスク開始
~/multi-agent-shogun/bin/update-progress.sh <足軽番号> 50 "タスク概要"

# タスク完了
~/multi-agent-shogun/bin/update-progress.sh <足軽番号> 100 "タスク完了"
```

詳細は [進捗共有.md](進捗共有.md) を参照。

---

## コンパクション復帰時の確認

1. **instructions/ashigaru.md** を読む（心得・禁止事項）
2. **queue/tasks/ashigaru{N}.yaml** を読む（自分のタスク）
3. **queue/reports/ashigaru{N}_report.yaml** を読む（自分の報告書）
4. **queue/shared/knowledge.yaml** を読む（共有知見）

```bash
# 自分の番号を確認
tmux display -t $TMUX_PANE -p "#{pane_index}"
```

## チェックリスト（報告前）

- [ ] status を記載したか？（done / failed / blocked）
- [ ] skill_candidate を記載したか？（found: false でも必須）
- [ ] next_action を記載したか？
- [ ] マニュアル引用を記載したか？
- [ ] ビルド確認を行ったか？（開発タスクの場合）

---

## マニュアル引用（必須）

```
【マニュアル確認】報告書.md より「skill_candidate は必須。found: false でも記載せよ」を確認した。
```

**引用がなければ読んでいない証拠。** 差し戻される。
