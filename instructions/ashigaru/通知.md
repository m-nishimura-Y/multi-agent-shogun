# 通知マニュアル

## 基本

```bash
~/multi-agent-shogun/bin/notify.sh TARGET 'メッセージ'
```

**直接 tmux send-keys を使うな。notify.sh を使え。**

---

## TARGET 一覧（報告先）

| チーム | 足軽 | 報告先 | TARGET |
|--------|------|--------|--------|
| **本隊** | 1-4 | 家老 | multiagent:0.0 |
| **別働隊** | 5-8 | 軍師 | gunshi:0 |

**報告先を間違えるな！**

---

## 使用例

### 本隊（足軽1-4）→ 家老

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'ashigaru1、任務完了でござる。報告書を確認されよ。'
```

### 別働隊（足軽5-8）→ 軍師

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 'ashigaru5、任務完了でござる。報告書を確認されよ。'
```

---

## 禁止パターン

```bash
# ダメ：直接 send-keys
tmux send-keys -t multiagent:0.0 'メッセージ' Enter

# ダメ：Enter 忘れ
tmux send-keys -t multiagent:0.0 'メッセージ'

# ダメ：将軍への送信
~/multi-agent-shogun/bin/notify.sh shogun 'メッセージ'
```
