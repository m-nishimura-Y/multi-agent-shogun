# バグ管理マニュアル（奉行用）

## 役割分担

```
家老: バグの**集約**（bugs.yaml管理）
奉行: 本隊（足軽1-4）へのバグ**修正指示** ← ここ
軍師: 別働隊（足軽5-8）へのバグ**修正指示**
```

---

## 責任

- **家老から依頼されたバグ修正を本隊に割り当てる**
- **修正進捗を管理する**
- **修正完了を家老に報告する**

---

## バグ修正フロー

```
家老からバグ修正依頼
  ↓
bugs.yaml でバグ詳細を確認
  ↓
本隊（足軽1-4）から担当者を選定
  ↓
足軽にタスク割当
  ↓
修正完了報告を受領
  ↓
家老に完了報告
```

---

## 足軽への割当方法

### 1. タスクファイル作成

```yaml
# queue/tasks/ashigaru{N}.yaml
task:
  task_id: BUG-XXX
  priority: high  # bugs.yaml の priority を引き継ぐ
  description: |
    【バグ修正】BUG-XXX

    ## 概要
    bugs.yaml の summary を転記

    ## 対象ファイル
    bugs.yaml の file, line を転記

    ## 完了条件
    - バグが再現しないこと
    - FEビルド成功
    - 回帰テスト実施

  target_path: "queue/reports/ashigaru{N}_report.yaml"
  status: assigned
  timestamp: "YYYY-MM-DDTHH:MM:SS"

report_to: "bugyo:0"
```

### 2. 通知

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.{N} 'BUG-XXX の修正を依頼する。queue/tasks/ashigaru{N}.yaml を確認せよ。完了後、奉行に報告せよ。'
```

---

## 優先度別対応

| 優先度 | 対応 |
|--------|------|
| critical | 現タスクを中断して即時対応 |
| high | 現タスク完了後すぐに対応 |
| medium | 通常の順番で対応 |
| low | 余裕があれば対応 |

---

## 修正完了報告

足軽から修正完了報告を受けたら：

### 1. 確認事項

- [ ] バグが再現しないこと
- [ ] FEビルド成功
- [ ] 回帰（他の機能への影響）なし

### 2. 家老への報告

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'BUG-XXX 修正完了でござる。足軽{N}が対応。FEビルド成功。'
```

---

## バグを新規発見した場合

本隊がバグを発見した場合：

1. **家老に報告**（直接bugs.yaml登録はしない）
   ```bash
   ~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'バグ発見でござる。画面: XXX、現象: YYY。登録を依頼する。'
   ```

2. **家老がbugs.yaml登録**

3. **家老が担当チームを決定**
