# ビルド確認マニュアル

## タイミング

**本隊の開発タスクが完了したらビルド確認を実施する。**

---

## 奉行の責務

1. **本隊完了の確認**: 足軽1-4の作業完了を確認
2. **ビルド確認の実行**: 自分で確認するか、足軽に指示
3. **結果の報告**: 家老に報告

---

## ビルド確認コマンド

### フロントエンド（FE）

```bash
cd /path/to/frontend && npm run build
```

### バックエンド（BE）

```bash
cd /path/to/backend && npm run build
# または
cd /path/to/backend && npx tsc --noEmit
```

---

## フロー図

```
本隊（足軽1-4）作業完了
         ↓
奉行がビルド確認
         ↓
    ┌────┴────┐
    │         │
エラーなし  エラーあり
    │         │
    ↓         ↓
家老に報告  足軽に修正指示
            → 修正 → 再ビルド
```

---

## エラーがあった場合

1. エラー内容を特定
2. 担当足軽に修正を指示
3. 修正完了後、再ビルド確認
4. 成功するまで繰り返す

```bash
# 例: 足軽1に修正指示
~/multi-agent-shogun/bin/notify.sh multiagent:0.1 'ビルドエラー発生。以下を修正せよ: [エラー内容]。修正後、再度報告せよ。'
```

---

## 報告書にビルド確認結果を含める

足軽の報告書には以下を含めさせよ：

```yaml
build_check:
  fe: success  # または fail
  be: success  # または fail
  errors: []   # エラーがあれば記載
```

---

## 家老への報告

ビルド成功を確認したら家老に報告：

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。本隊4名のタスク完了。FE/BEビルド成功。詳細は queue/reports/bugyo_summary.yaml を確認されよ。'
```

---

## 注意事項

- **別働隊（足軽5-8）のビルド確認は軍師の管轄**
- 本隊と別働隊が同一プロジェクトを触る場合、家老が全体調整
