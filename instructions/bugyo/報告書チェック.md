# 報告書チェックマニュアル

## 目的

足軽からの報告書の品質を守る。不備があれば差し戻し、品質を担保せよ。

---

## チェックリスト

足軽からの報告を受けたら、以下を確認せよ：

```
[ ] status: done / failed / blocked のいずれか
[ ] skill_candidate: found: true/false が記載されている
[ ] next_action: 記載されている（コンパクション復帰用）
[ ] マニュアル引用: 「○○.md より『引用文』」がある
[ ] スキル使用: 推奨スキルを使用したか
[ ] ビルド確認: FE/BE ビルド成功の記載がある（開発タスクの場合）
```

---

## 必須項目の詳細

### 1. status（必須）

| 値 | 意味 |
|----|------|
| done | タスク完了 |
| failed | 失敗（原因を確認せよ） |
| blocked | ブロック（何に阻まれているか確認） |

### 2. skill_candidate（必須）

```yaml
# 候補あり
skill_candidate:
  found: true
  name: "xxx-analyzer"
  description: "説明"

# 候補なし（これも記載必須）
skill_candidate:
  found: false
```

**`found: false` でも記載必須。** 空欄は不可。

### 3. next_action（必須）

```yaml
next_action: "次タスク待機中"
```

コンパクション復帰時に何をすべきか分かるように記載。

### 4. マニュアル引用（必須）

```
【マニュアル確認】報告書.md より「skill_candidate は必須。found: false でも記載せよ」を確認した。
```

**引用がなければ読んでいない証拠。** 差し戻せ。

### 5. スキル使用

推奨スキルを指定した場合：
- 使用したか確認
- 使用していなければ理由を確認

```yaml
# タスク指示時
recommended_skills:
  - react-mui-crud-scaffold

# 報告書で確認
skills_used:
  - react-mui-crud-scaffold  # 使用した
# または
skills_used: []  # 使用しなかった場合、理由を確認
```

## 不備があった場合

差し戻しメッセージを送信せよ：

```bash
# skill_candidate が抜けている場合
~/multi-agent-shogun/bin/notify.sh multiagent:0.1 '報告書に skill_candidate の記載がないぞ。found: false でも必須でござる。修正して再報告せよ。'

# マニュアル引用がない場合
~/multi-agent-shogun/bin/notify.sh multiagent:0.2 '報告書に【マニュアル確認】の引用がない。instructions/ashigaru.md を読んでから再報告せよ。'

# 推奨スキルを使わなかった場合（理由確認）
~/multi-agent-shogun/bin/notify.sh multiagent:0.3 '推奨スキル react-mui-crud-scaffold を使用しなかった理由を報告書に追記せよ。'
```

## 家老への報告集約

本隊4名の報告を受けたら、要点をまとめて家老に報告：

```yaml
# queue/reports/bugyo_summary.yaml
report_type: hontai_summary
timestamp: "YYYY-MM-DDTHH:MM:SS"
cmd_id: cmd_XXX
summary: "本隊4名の報告を集約"

reports:
  - ashigaru: 1
    status: done
    summary: "タスクA完了"
    skill_candidate: null
  - ashigaru: 2
    status: done
    summary: "タスクB完了"
    skill_candidate:
      name: "xxx-generator"
      evaluation_needed: true

skill_candidates:
  - name: "xxx-generator"
    from: ashigaru2
    needs_evaluation: true

awaiting: karo_review
```

## 家老への通知

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。本隊4名のタスク完了。詳細は queue/reports/bugyo_summary.yaml を確認されよ。スキル候補1件あり。'
```
