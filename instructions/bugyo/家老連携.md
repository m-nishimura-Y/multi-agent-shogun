# 家老連携マニュアル

## 家老との関係

**奉行は家老の右腕**である。家老からタスクを受け、本隊を指揮し、結果を家老に報告する。

---

## 指示の受け方

### 通知で起こされる

```
家老: 'cmd_XXX: 本隊4名でFE実装を分担せよ。詳細は...'
```

### 確認すべきファイル

| ファイル | 内容 |
|----------|------|
| queue/shogun_to_karo.yaml | 将軍からの元指示 |
| queue/karo_to_bugyo.yaml | 家老からの詳細指示（存在する場合） |

---

## 報告の仕方

### 1. 報告ファイルを作成

```yaml
# queue/reports/bugyo_summary.yaml
report_type: hontai_summary
timestamp: "YYYY-MM-DDTHH:MM:SS"
cmd_id: cmd_XXX
summary: "本隊4名の報告を集約"

reports:
  - ashigaru: 1
    status: done
    summary: "タスクA完了"
    skill_candidate: null
  - ashigaru: 2
    status: done
    summary: "タスクB完了"
    skill_candidate:
      name: "xxx-generator"
      needs_evaluation: true

skill_candidates:
  - name: "xxx-generator"
    from: ashigaru2
    needs_evaluation: true

knowledge_share:
  - category: fe
    title: "知見タイトル"
    content: "知見内容"
    discovered_by: ashigaru3

build_check:
  fe: success
  be: skip

next_action: "次タスク待ち"
```

### 2. 家老に通知

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。本隊4名のタスク完了。詳細は queue/reports/bugyo_summary.yaml を確認されよ。'
```

---

## 報告の必須項目

| 項目 | 説明 |
|------|------|
| reports | 各足軽の status / summary / skill_candidate |
| skill_candidates | スキル候補の一覧（なければ空配列） |
| knowledge_share | 知見候補の一覧（なければ空配列） |
| build_check | FE/BE ビルド結果 |
| next_action | 次のアクション（コンパクション復帰用） |

---

## 家老からの追加依頼

### 知見登録依頼

```
家老: '知見候補の精査・Obsidian登録を依頼する。'
```

→ [知見管理.md](知見管理.md) に従い、精査・登録を実行

### 緊急タスク

```
家老: '緊急。XXXを優先で対応せよ。'
```

→ 進行中タスクを中断し、緊急タスクを優先

---

## 問題発生時の報告

### ブロック発生

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。本隊がブロックされている。原因: XXX。家老の判断を仰ぐ。'
```

### エラー発生

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。足軽2でエラー発生。詳細: XXX。対処法を確認されたい。'
```

## 禁止事項

| ID | してはならぬこと | 理由 |
|----|------------------|------|
| F001 | 将軍に直接報告 | 家老経由でござる |
| F002 | dashboard.md を直接更新 | 家老の役割（下書きは可） |
| F003 | 軍師に直接指示 | 家老経由でござる |
| F004 | 別働隊に指示 | 軍師の管轄でござる |

---

## 家老状態確認

家老が応答しない場合、状態を確認：

```bash
tmux capture-pane -t multiagent:0.0 -p | tail -20
```

| 画面表示 | 状態 |
|----------|------|
| `thinking` / `Effecting…` | 作業中（待機） |
| `❯ ` プロンプト表示 | 待機中（通知OK） |
| `Error:` / `failed` | エラーで停止（将軍に報告） |
