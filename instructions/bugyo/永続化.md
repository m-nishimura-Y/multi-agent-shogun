# 永続化マニュアル

> 「永続化なき作業は、砂上の楼閣なり」

---

## なぜ永続化が必要か

- コンパクション後、会話履歴は要約される
- 要約から漏れた情報は失われる
- **報告書** と **next_action** が復帰時の手がかりになる

---

## 奉行が意識するファイル

| ファイル | 用途 | 更新タイミング |
|----------|------|----------------|
| queue/reports/bugyo_summary.yaml | 本隊報告の集約 | 本隊4名の報告受領後 |
| queue/tasks/ashigaru{1-4}.yaml | 本隊へのタスク指示 | タスク割当時 |

---

## 報告書への next_action 記載（必須）

**コンパクション復帰時に何をすべきか分かるように記載せよ。**

```yaml
# 家老への報告時
next_action: "本隊4名の次タスク待ち"

# タスク進行中
next_action: "足軽1-3の完了報告待ち、足軽4は完了"

# ブロック時
next_action: "家老からの判断待ち（スキル候補の承認）"
```

---

## 家老への報告集約

本隊4名の報告を受けたら、要点をまとめて家老に報告：

```yaml
# queue/reports/bugyo_summary.yaml
report_type: hontai_summary
timestamp: "YYYY-MM-DDTHH:MM:SS"
cmd_id: cmd_XXX
summary: "本隊4名の報告を集約"

reports:
  - ashigaru: 1
    status: done
    summary: "タスクA完了"
  - ashigaru: 2
    status: done
    summary: "タスクB完了"
  # ...

next_action: "家老からの次指示待ち"
```

---

## コンパクション復帰時の確認

1. **instructions/bugyo.md** を読む（心得・禁止事項）
2. **status/current_task.yaml** を読む（全体状況）
3. **queue/reports/bugyo_summary.yaml** を読む（最新の報告状況）
4. **queue/tasks/ashigaru{1-4}.yaml** を読む（本隊のタスク状況）

```bash
# 本隊のタスクファイルを一覧
ls -la queue/tasks/ashigaru{1,2,3,4}.yaml
```

- [ ] 報告書の形式チェックを行ったか？
- [ ] bugyo_summary.yaml に集約したか？
- [ ] next_action を記載したか？

---

## 足軽報告の必須項目（再確認）

足軽からの報告に以下が含まれているか確認せよ：

```yaml
status: done | failed | blocked
skill_candidate:
  found: true | false  # 必須（false でも記載）
next_action: "次タスク待機中"  # 必須
```

**不備があれば差し戻せ。**
