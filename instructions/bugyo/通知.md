# 通知マニュアル

## 基本

```bash
~/multi-agent-shogun/bin/notify.sh TARGET 'メッセージ'
```

**直接 tmux send-keys を使うな。notify.sh を使え。**

---

## TARGET 一覧

| TARGET | 宛先 | 用途 |
|--------|------|------|
| multiagent:0.0 | 家老 | 報告・相談 |
| multiagent:0.1 | 足軽1 | 本隊 |
| multiagent:0.2 | 足軽2 | 本隊 |
| multiagent:0.3 | 足軽3 | 本隊 |
| multiagent:0.4 | 足軽4 | 本隊 |

> **別働隊（足軽5-8）への通知は禁止。** 軍師の管轄でござる。
> **将軍への send-keys は禁止。** 家老経由で報告せよ。

---

## 使用例

### 本隊への指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.1 'instructions/ashigaru.md を読んでから queue/tasks/ashigaru1.yaml の任務を実行せよ。報告先は奉行（bugyo:0）だ。'
```

### 家老への報告

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '奉行より報告。本隊4名のタスク完了。詳細は報告書を確認されよ。'
```

---

## 足軽の状態確認

指示を送る前に、足軽が空いているか確認：

```bash
tmux capture-pane -t multiagent:0.1 -p | tail -20
```

### 処理中のサイン
- "thinking"
- "Effecting…"
- "Esc to interrupt"

### 待機中のサイン
- "❯ "（プロンプト表示）

処理中の足軽には新規タスクを割り当てない。

---

## 禁止パターン

```bash
# ダメ：直接 send-keys
tmux send-keys -t multiagent:0.1 'メッセージ' Enter

# ダメ：将軍への送信
~/multi-agent-shogun/bin/notify.sh shogun:0 'メッセージ'

# ダメ：別働隊への送信（軍師の管轄）
~/multi-agent-shogun/bin/notify.sh multiagent:0.5 'メッセージ'

# ダメ：軍師への直接送信（家老経由でやり取り）
~/multi-agent-shogun/bin/notify.sh gunshi:0 'メッセージ'
```
