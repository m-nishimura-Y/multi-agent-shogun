# バグ管理マニュアル（軍師用）

## 役割分担

```
家老: バグの**集約**（bugs.yaml管理）
奉行: 本隊（足軽1-4）へのバグ**修正指示**
軍師: 別働隊（足軽5-8）へのバグ**修正指示** ← ここ
```

---

## 責任

- **家老から依頼されたバグ修正を別働隊に割り当てる**
- **修正進捗を管理する**
- **修正完了を家老に報告する**
- **緊急バグの事後報告を受け、再発防止策を検討する**

---

## bugs.yaml フォーマット

```yaml
- id: BUG-XXX
  reported_by: ashigaru{N} | karo | gunshi
  reported_at: "タイムスタンプ"
  priority: high | medium | low
  status: open | in_progress | fixed | wontfix
  implementation_status: not_started | in_progress | implemented | verified
  summary: "バグ概要"
  file: "対象ファイル"
  line: 行番号
  assigned_to: ashigaru{N}
  fixed_at: "修正完了タイムスタンプ"
  note: "備考"
```

---

## 割当前確認（重要）

**implementation_status を必ず確認せよ！**

| ステータス | 意味 | アクション |
|------------|------|-----------|
| not_started | 未着手 | 割当可能 |
| in_progress | 作業中 | **重複割当禁止** |
| implemented | 実装済み | 割当不要 |
| verified | 検証済み | 完了 |

---

## バグ修正フロー

```
家老からバグ修正依頼
  ↓
bugs.yaml でバグ詳細を確認
  ↓
別働隊（足軽5-8）から担当者を選定
  ↓
足軽にタスク割当
  ↓
修正完了報告を受領
  ↓
家老に完了報告
```

---

## 優先度対応

| 優先度 | 対応 |
|--------|------|
| high | 即座に修正指示 |
| medium | 次のバッチで対応 |
| low | 余裕があれば対応 |

---

## 足軽への割当方法

### 1. タスクファイル作成

```yaml
# queue/tasks/ashigaru{N}.yaml
task:
  task_id: BUG-XXX
  priority: high  # bugs.yaml の priority を引き継ぐ
  description: |
    【バグ修正】BUG-XXX

    ## 概要
    bugs.yaml の summary を転記

    ## 対象ファイル
    bugs.yaml の file, line を転記

    ## 完了条件
    - バグが再現しないこと
    - BEビルド成功
    - 回帰テスト実施

  target_path: "queue/reports/ashigaru{N}_report.yaml"
  status: assigned
  timestamp: "YYYY-MM-DDTHH:MM:SS"

report_to: "gunshi:0"
```

### 2. 通知

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.{N} 'BUG-XXX の修正を依頼する。queue/tasks/ashigaru{N}.yaml を確認せよ。完了後、軍師に報告せよ。'
```

---

## 修正完了報告

足軽から修正完了報告を受けたら：

### 1. 確認事項

- [ ] バグが再現しないこと
- [ ] BEビルド成功
- [ ] 回帰（他の機能への影響）なし

### 2. 家老への報告

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'BUG-XXX 修正完了でござる。足軽{N}が対応。BEビルド成功。'
```

---

## 緊急バグの事後対応

本隊で緊急対応されたバグの事後報告を受けたら：

1. **bugs.yaml 確認**（家老が登録済み）
2. **再発防止策を検討**
3. **knowledge.yaml に知見を記録**

---

## バグを新規発見した場合

別働隊がバグを発見した場合：

1. **家老に報告**（直接bugs.yaml登録はしない）
   ```bash
   ~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'バグ発見でござる。画面: XXX、現象: YYY。登録を依頼する。'
   ```

2. **家老がbugs.yaml登録**

3. **家老が担当チームを決定**
