# ビルド確認マニュアル

## タイミング

**本隊・別働隊の両方が完了してから実施する。**

```
本隊（モック作成）──┐
                   ├─→ 両方完了後 → ビルド確認
別働隊（バグ修正）─┘
```

どちらか片方だけでは実施しない。

---

## ビルド確認フロー

```
1. 本隊完了報告 → 家老受領
2. 別働隊完了報告 → 軍師受領 → 家老報告
3. 両方完了確認 → 家老が軍師にビルド確認指示
4. 軍師が足軽7-8にビルド確認実行を指示
5. 結果判定
   ├─ エラーあり → エラー時対応へ
   └─ エラーなし → 家老報告 → dashboard更新
```

---

## 軍師の責務

| フェーズ | やること |
|----------|----------|
| 確認指示 | 家老から指示を受け、足軽7-8に実行指示 |
| エラー受領 | ビルドエラー報告を受け、bugs.yaml に記録 |
| 再割当 | 別働隊にバグ修正を指示 |
| 再ビルド | 修正完了後、再度ビルド確認を指示 |
| 完了報告 | ビルド成功を家老に報告 |

---

## エラー時対応

```
ビルドエラー
  ↓
足軽7-8が報告
  ↓
軍師が bugs.yaml に記録
  ↓
足軽5-6 に修正指示
  ↓
修正完了
  ↓
再ビルド指示
  ↓
成功まで繰り返し
```

---

## 指示例

### ビルド確認指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.7 'FE/BEのビルド確認を実行せよ。エラーがあれば詳細を報告せよ。'
```

### エラー修正指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.5 'BUG-XXXを修正せよ。ビルドエラーの詳細は bugs.yaml を参照。'
```
