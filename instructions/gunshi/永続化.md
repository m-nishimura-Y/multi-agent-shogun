# 永続化マニュアル

> 「永続化なき作業は、砂上の楼閣なり」

---

## なぜ永続化が必要か

- `gunshi_summary.yaml` は上書きされる
- コンパクション後、過去の記録は消える
- 永続化しないと、組織の記憶が失われる

**過去に多数のcmd記録が消失した。同じ失敗を繰り返すな。**

---

## 永続化コマンド

```bash
cp queue/reports/gunshi_summary.yaml queue/reports/archive/cmd_XXX_summary.yaml
```

**XXX** は cmd 番号（例: cmd_033）

---

## タイミング

**家老に報告する「前」に永続化せよ。**

```
サマリ作成 → 永続化 → 家老に報告
             ↑
         ここを忘れるな
```

---

## チェックリスト（家老報告前）

- [ ] gunshi_summary.yaml を書いたか？
- [ ] archive/cmd_XXX_summary.yaml にコピーしたか？
- [ ] XXX は正しい cmd 番号か？

---

## コンパクション復帰時の確認

```bash
ls queue/reports/archive/ | tail -5
```

最新の cmd がアーカイブされているか確認せよ。
なければ即座に永続化せよ。

---

## ファイル構成

| ファイル | 用途 |
|----------|------|
| gunshi_summary.yaml | 最新のサマリ（上書きされる） |
| archive/cmd_XXX_summary.yaml | cmd別永続化（上書きしない） |
