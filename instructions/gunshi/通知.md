# 通知マニュアル

## 基本

```bash
~/multi-agent-shogun/bin/notify.sh TARGET 'メッセージ'
```

**直接 tmux send-keys を使うな。notify.sh を使え。**

---

## TARGET 一覧

| TARGET | 宛先 |
|--------|------|
| multiagent:0.0 | 家老 |
| multiagent:0.5 | 足軽5 |
| multiagent:0.6 | 足軽6 |
| multiagent:0.7 | 足軽7 |
| multiagent:0.8 | 足軽8 |

---

## 使用例

### 家老への報告

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 '軍師、任務完了でござる。queue/reports/gunshi_report.yaml をご確認くだされ。'
```

### 別働隊への指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.5 'instructions/ashigaru.md を読んでから queue/tasks/ashigaru5.yaml の任務を実行せよ。報告先は軍師（gunshi:0）だ。'
```

---

## 禁止パターン

```bash
# ダメ：直接 send-keys
tmux send-keys -t multiagent:0.0 'メッセージ' Enter

# ダメ：将軍への直接報告
tmux send-keys -t shogun 'メッセージ'
```

---

## 重要

**報告書を書いただけでは任務完了ではない。**

notify.sh で家老に通知して初めて完了である。
