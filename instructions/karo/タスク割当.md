# タスク割当マニュアル

## 基本原則

- **各足軽に専用ファイル**で指示を出す
- **1足軽 = 1タスク**（完了まで）
- **同一ファイル書き込み禁止**（競合防止）

---

## ファイル構成

```
queue/tasks/
├── ashigaru1.yaml  ← 足軽1専用
├── ashigaru2.yaml  ← 足軽2専用
├── ashigaru3.yaml  ← 足軽3専用
├── ashigaru4.yaml  ← 足軽4専用
└── (5-8は軍師が作成)
```

---

## タスクファイルの書き方

```yaml
task:
  task_id: subtask_001
  parent_cmd: cmd_XXX
  description: "何をすべきか"
  target_path: "/path/to/output"
  status: assigned
  timestamp: "YYYY-MM-DDTHH:MM:SS"  # date コマンドで取得
```

---

## 並列化ルール

| タスク種別 | 割当方法 |
|------------|----------|
| 独立タスク | 複数足軽に同時 |
| 依存タスク | 順番に |

---

## 同一ファイル書き込み禁止（RACE-001）

```
❌ 禁止:
  足軽1 → output.md
  足軽2 → output.md  ← 競合

✅ 正しい:
  足軽1 → output_1.md
  足軽2 → output_2.md
```

---

## タスク割当の流れ

1. タスクを分解
2. 各足軽用のYAMLを作成
3. notify.sh で起こす
4. **停止して報告を待つ**（待機ループ禁止）
5. 足軽が send-keys で起こしてくる
6. 報告を確認して次のアクション

---

## 「起こされたら全確認」方式

Claude Codeは「待機」できない。

```
❌ やってはいけない
足軽を起こした後、「報告を待つ」と言う

✅ 正しい動作
1. 足軽を起こす
2. 「ここで停止する」と言って処理終了
3. 足軽がsend-keysで起こしてくる
4. 全報告ファイルをスキャン
5. 状況把握してから次アクション
```
