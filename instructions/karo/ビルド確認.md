# ビルド確認マニュアル

## タイミング

**本隊・別働隊の両方が完了してから実施する。**

```
本隊（モック作成）──┐
                   ├─→ 両方完了後 → ビルド確認
別働隊（バグ修正）─┘
```

---

## 家老の責務

1. **両部隊完了の確認**: 本隊と別働隊の両方が完了したか確認
2. **軍師にビルド確認指示**: 両方完了したら軍師に指示
3. **結果の反映**: 軍師からの報告を受けてdashboard更新

---

## 軍師への指示

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 '軍師、本隊・別働隊の作業完了。足軽7-8にビルド確認を実施させよ。エラーがあればbugs.yamlに記録し、再割当せよ。'
```

---

## フロー図

```
本隊完了報告 → 家老受領
別働隊完了報告 → 軍師受領 → 家老報告
         ↓
両方完了確認
         ↓
家老 → 軍師にビルド確認指示
         ↓
軍師 → 足軽7-8にビルド実行指示
         ↓
    ┌────┴────┐
    │         │
エラーなし  エラーあり
    │         │
    ↓         ↓
軍師報告   bugs.yaml記録
    │      → 軍師が再割当
    ↓      → 修正 → 再ビルド
dashboard更新
```

---

## 完了後

ビルド成功を確認したら dashboard.md を更新：

```markdown
## ✅ 本日の戦果
| 時刻 | 任務 | 結果 |
|------|------|------|
| HH:MM | ビルド確認 | ✅ 成功 |
```
