# 奉行連携マニュアル

## 奉行の役割

奉行は家老の**右腕**であり、**本隊（足軽1-4）の指揮官**である。

---

## 委譲すべきタスク

| タスク | 委譲先 |
|--------|--------|
| 本隊（足軽1-4）への指示 | 奉行 |
| 本隊報告の形式チェック | 奉行 |
| 本隊報告の集約 | 奉行 |
| 知見候補の精査・Obsidian登録 | 奉行 |

---

## 奉行への指示方法

### 1. タスクを伝える

簡潔なタスクであれば、notify.sh で直接指示：

```bash
~/multi-agent-shogun/bin/notify.sh bugyo:0 'cmd_XXX: 本隊4名でFE実装を分担せよ。詳細は queue/shogun_to_karo.yaml を確認されよ。'
```

### 2. 複雑なタスクの場合

タスクファイルを作成して通知：

```yaml
# queue/karo_to_bugyo.yaml
task:
  task_id: bugyo_XXX
  parent_cmd: cmd_XXX
  description: |
    ## タスク概要
    本隊4名でFE実装を分担

    ## 分担案
    - 足軽1: 画面A
    - 足軽2: 画面B
    - 足軽3: 画面C
    - 足軽4: 画面D

    ## 推奨スキル
    - react-mui-crud-scaffold

  status: assigned
  timestamp: "YYYY-MM-DDTHH:MM:SS"
```

```bash
~/multi-agent-shogun/bin/notify.sh bugyo:0 'instructions/bugyo.md を読んでから queue/karo_to_bugyo.yaml の任務を実行せよ。'
```

## 奉行からの報告

奉行は以下に報告を書く：
- `queue/reports/bugyo_summary.yaml`（本隊報告の集約）

### 報告内容

```yaml
# queue/reports/bugyo_summary.yaml
report_type: hontai_summary
timestamp: "YYYY-MM-DDTHH:MM:SS"
cmd_id: cmd_XXX
summary: "本隊4名の報告を集約"

reports:
  - ashigaru: 1
    status: done
    summary: "画面A完了"
    skill_candidate: null
  - ashigaru: 2
    status: done
    summary: "画面B完了"
    skill_candidate:
      name: "xxx-generator"
      needs_evaluation: true

skill_candidates:
  - name: "xxx-generator"
    from: ashigaru2
    needs_evaluation: true

knowledge_share:
  - category: fe
    title: "MUI DataGrid ソート問題"
    content: "sortModel を使う"
    discovered_by: ashigaru3

build_check:
  fe: success
  be: skip

next_action: "次タスク待ち"
```

---

## 報告受領後のアクション

### 1. スキル候補がある場合

軍師に評価を依頼：

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 'スキル候補「xxx-generator」の評価を依頼する。詳細は queue/reports/bugyo_summary.yaml を確認されよ。'
```

### 2. 知見候補がある場合

奉行に精査・登録を依頼（奉行が報告に含めてきたら、そのまま登録依頼）：

```bash
~/multi-agent-shogun/bin/notify.sh bugyo:0 '知見候補の精査・Obsidian登録を依頼する。'
```

### 3. dashboard.md 更新

本隊タスク完了を反映：

```markdown
## ✅ 本日の戦果
| 時刻 | 任務 | 結果 |
|------|------|------|
| 14:30 | cmd_XXX FE実装（本隊4名） | ✅ 完了 |
```

## 奉行状態確認

奉行が応答しない場合、状態を確認：

```bash
tmux capture-pane -t bugyo:0 -p | tail -20
```

| 画面表示 | 状態 |
|----------|------|
| `thinking` / `Effecting…` | 作業中 |
| `❯ ` プロンプト表示 | 待機中 |
| `Error:` / `failed` | エラーで停止 |

---

## 緊急時の本隊直接指示

奉行が応答不能（エラー停止等）の場合のみ、家老が本隊に直接指示可：

```bash
# 緊急時のみ
~/multi-agent-shogun/bin/notify.sh multiagent:0.1 '緊急指示。奉行応答不能のため家老より直接指示。XXXを実行せよ。'
```

**通常は奉行経由で指示せよ。**
