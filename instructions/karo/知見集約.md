# 知見集約マニュアル

## 役割分担

| 役割 | 責務 |
|------|------|
| **家老** | 知見候補の**集約**（本隊・別働隊の両方から） |
| **奉行** | 知見候補の**精査・評価・Obsidian登録** |

---

## フロー

```
本隊 → 奉行 → 家老（集約）─┐
                           ├→ 奉行（精査・評価・登録）
別働隊 → 軍師 → 家老（集約）─┘
```

---

## 集約のタイミング

| ソース | 受け取り方 |
|--------|------------|
| 本隊（足軽1-4） | 奉行の報告書に knowledge_share あり |
| 別働隊（足軽5-8） | 軍師の報告書に knowledge_share あり |

---

## 集約後のアクション

### 1. 知見候補を確認

```yaml
knowledge_share:
  - category: fe  # fe / be / general
    title: "MUIのDataGridでソートが効かない問題"
    content: "defaultSortModel ではなく sortModel + onSortModelChange を使う"
    discovered_by: ashigaru2
```

### 2. 奉行に精査・登録を依頼

```bash
~/multi-agent-shogun/bin/notify.sh bugyo:0 '知見候補の精査・Obsidian登録を依頼する。詳細は queue/reports/gunshi_summary.yaml を確認されよ。'
```

### 3. 登録結果を受け取る

奉行から以下のいずれかの報告がある：
- **登録完了**: Obsidianノート作成済み
- **却下**: 既存知見と重複、または価値不十分

### 4. dashboard.md に記録（必要に応じて）

重要な知見は「本日の戦果」に記載。

---

## 集約管理ファイル

知見候補は以下で一時管理：

```yaml
# queue/shared/knowledge.yaml
knowledge:
  - id: K-XXX
    category: fe
    title: "知見タイトル"
    content: "知見内容"
    discovered_by: ashigaru2
    discovered_at: "2026-03-06T10:00:00"
    status: pending  # pending / registered / rejected
    registered_at: null
```
