# 軍師連携マニュアル

## 軍師の役割

軍師は家老の**参謀・秘書**である。

---

## 委譲すべきタスク

| タスク | 委譲先 |
|--------|--------|
| 別働隊（足軽5-8）への指示 | 軍師 |
| スキル評価 | 軍師 |
| バグ管理（bugs.yaml） | 軍師 |
| 提案管理（proposals.yaml） | 軍師 |
| Web検索・リサーチ | 軍師 |
| 報告書の集約・整理 | 軍師 |

---

## 軍師への指示方法

### 1. 指示ファイルを作成

```yaml
# queue/karo_to_gunshi.yaml
task:
  task_id: gunshi_XXX
  parent_cmd: cmd_XXX
  type: task_distribution | skill_evaluation | research | summarize
  description: "何をすべきか"
  ashigaru_tasks:  # task_distribution の場合
    - ashigaru_id: 5
      description: "タスクA"
    - ashigaru_id: 6
      description: "タスクB"
  status: assigned
  timestamp: "YYYY-MM-DDTHH:MM:SS"
```

### 2. 軍師を起こす

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 'instructions/gunshi.md を読んでから queue/karo_to_gunshi.yaml の任務を実行せよ。'
```

## 軍師からの報告

軍師は以下に報告を書く：
- `queue/reports/gunshi_report.yaml`（分析結果等）
- `queue/reports/gunshi_summary.yaml`（足軽報告集約）

---

## Obsidian登録（v1.6.5追加）

軍師からサマリ報告を受領したら、`obsidian_worthy` を確認：

```yaml
# gunshi_summary.yaml に含まれる
obsidian_worthy: true
obsidian_category: "知見/成功事例"
obsidian_title: "cmd_XXX: タイトル"
obsidian_summary: "概要"
```

### obsidian_worthy: true の場合

Obsidian MCP でノートを作成：

```
mcp__obsidian__obsidian_update_note を使用
- targetType: "filePath"
- targetIdentifier: "{obsidian_category}/{obsidian_title}.md"
- content: 報告内容をMarkdown形式で
- modificationType: "wholeFile"
- wholeFileMode: "overwrite"
- createIfNeeded: true
```

### 登録後

dashboard.md の本日の戦果に「📚」を付記：

```
| 13:35 | project | cmd_045: タスク名 | ✅ 完了 📚 |
```

### obsidian_worthy: false の場合

Obsidian登録は不要。通常のdashboard更新のみ。

## 永続化チェック（重要）

軍師からcmd完了報告を受けたら確認：

```bash
ls queue/reports/archive/ | grep cmd_XXX
```

**存在しなければ軍師に指摘：**

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 '軍師、永続化を忘れておるぞ。archive/cmd_XXX_summary.yaml にコピーせよ。'
```
