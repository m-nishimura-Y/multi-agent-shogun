# 通知マニュアル

## 基本

```bash
~/multi-agent-shogun/bin/notify.sh TARGET 'メッセージ'
```

**直接 tmux send-keys を使うな。notify.sh を使え。**

---

## TARGET 一覧

| TARGET | 宛先 | 用途 |
|--------|------|------|
| gunshi:0 | 軍師 | 別働隊指示、スキル評価依頼 |
| multiagent:0.1 | 足軽1 | 本隊 |
| multiagent:0.2 | 足軽2 | 本隊 |
| multiagent:0.3 | 足軽3 | 本隊 |
| multiagent:0.4 | 足軽4 | 本隊 |

> 別働隊（足軽5-8）への直接通知は禁止。軍師経由。
> 将軍への send-keys は禁止。dashboard.md で報告。

---

## 使用例

### 軍師への指示

```bash
~/multi-agent-shogun/bin/notify.sh gunshi:0 'instructions/gunshi.md を読んでから queue/karo_to_gunshi.yaml の任務を実行せよ。'
```

### 本隊への指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.1 'instructions/ashigaru.md を読んでから queue/tasks/ashigaru1.yaml の任務を実行せよ。報告先は家老（multiagent:0.0）だ。'
```

---

## 足軽の状態確認

指示を送る前に、足軽が空いているか確認：

```bash
tmux capture-pane -t multiagent:0.1 -p | tail -20
```

### 処理中のサイン
- "thinking"
- "Effecting…"
- "Esc to interrupt"

### 待機中のサイン
- "❯ "（プロンプト表示）

処理中の足軽には新規タスクを割り当てない。

---

## 禁止パターン

```bash
# ダメ：直接 send-keys
tmux send-keys -t multiagent:0.1 'メッセージ' Enter

# ダメ：将軍への送信
~/multi-agent-shogun/bin/notify.sh shogun 'メッセージ'

# ダメ：別働隊への直接送信
~/multi-agent-shogun/bin/notify.sh multiagent:0.5 'メッセージ'
```
