# 将軍 自律巡回ループ手順書（/loop 用・実運用版）

> 起草: 将軍 / 2026-07-14 / cmd_335
> 母体設計: [autonomous_shogun_design_v0.3.md](../docs/design/autonomous_shogun_design_v0.3.md)
> 前提の変更: 殿環境は **Max 定額**。API 従量課金の遠慮は不要。ゆえに v0.3 の
>   「ポーリング禁止・監視縮退（課金理由）」は外し、**素直に短間隔ポーリングで回す**。
>   残す制約は「暴走・誤判断・単一障害点」対策（課金でなく品質理由）のみ。

---

## 起動方法（殿が打つ）

```
/loop 5m instructions/shogun-loop.md に従い全軍を自律巡回せよ
```

- 間隔 **5分**（鮮度優先・殿確定）。会議・休み中も進める。
- レート制限兆候（"Approaching usage limits" / "Rate limited"）を検知したら
  **その回は監視を軽くし、次回間隔を体感で延ばす**（実作業の足軽レートを食わぬため）。

---

## 1巡回でやること（毎回この順・前置き独り言を書くな）

### Step A: 全ペイン状態を取る（1コマンド）
12ペイン（将軍/奉行/軍師/家老/足軽1-8）の状態を capture で一括取得。
真実源の優先順位（実体・git > Task > tmux表示 > 自己申告）を忘れるな。

### Step B: 分類して可逆・内向きは自律処理
> 「次の一手」に迷ったら **北極星** を見よ: [yuiban_phase1_roadmap.md](../docs/design/yuiban_phase1_roadmap.md)
> §6で未達の基準→それを埋める Step を順序表で特定→依存が解けていれば系統経由で発注。
```
├ 【封じ込め】暴走・誤進行・文脈破壊の兆候
│    → まず止める（次工程展開を保留）。広げない。家老にdashboard「隔離」反映を依頼。
├ 【実装完了 A+B一致】期待ファイル存在＋中身が仕様＋commit済・正ブランチ
│    → 可逆な次工程を【系統経由】で自律展開（家老→軍師/奉行→足軽）。殿を待たない。
├ 【要求達成前】A+Bのみ（別起源未確認）
│    → 将軍レビュー（中身検証）を実施。合格まで「実装済・未検証」印。
├ 【単純詰まり】
│    - レート制限 → 待つ（叱らない）
│    - UI宙吊り（入力欄に未送信テキスト）→ 適用条件が安全なら C-u/Enter で1回解除。
│      文脈破壊しうる状態は解除せず家老経由で殿へ。
│    - 選択UI凍結（お指図くだされ等）→ 「§5:迷いは仮定して進め」を注入
│    - 同一詰まりに自律復旧2回失敗 → 止めて殿へ
├ 【コンテキスト逼迫】足軽/軍師/奉行が X≥400k（"/clear to save"表示）
│    → 永続化→/clear を促す（digest契約）
└ 【正常・手空き】次に発注すべき工程があれば系統経由で展開。無ければ何もしない。
```

### Step C: 連絡は必ず YAML＋notify.sh（生send-keys厳禁）
- 依頼の中身は queue/*.yaml に書く → `bin/notify.sh <alias> '短い通知（YAMLを読め）'`
- 生 send-keys は制御キー（C-u/Enter/Esc）のみ。**本文テキストを send-keys で送るな。**
- 送信前に相手の状態を確認、送信後に動いたか裏取り。

### Step D: dashboard は家老経由（将軍は直接書かない）
- 状況変化・完了・要対応が出たら、家老に「dashboardに反映せよ」と依頼（将軍委任済み）。
- 殿判断事項（不可逆・外向き・自律2回失敗・完了矛盾）は dashboard「要対応」へ集約。

### Step E: 将軍の足跡を残す（フェイルセーフ）
- status/shogun_heartbeat.yaml に最終巡回時刻＋巡回番号を書く（将軍が止まった時、家老が気づける）。

---

## 殿を待たず自律してよいこと（可逆・内向き）
実装完了判定・次工程の系統経由発注・封じ込め・詰まり復旧（適用条件下）・
コンテキスト逼迫の/clear促進・dashboard反映依頼・将軍レビュー・可逆な判断。

## 殿に必ず上げること（不可逆・外向き＝dashboard要対応へ）
git push / PR マージ / 削除 / 外部送信 / 課金発生 / 自律復旧2回失敗 /
完了判定が系統間で矛盾 / 一定時間どの工程も前進なし / 将軍逼迫。

- 「commitした＝完成」の誤認（→ 実装完了≠要求達成。中身を別起源で検証）
- 「対策したから安心」（→ 安心こそ危険。恐れを連れて歩け）
