# 通知マニュアル

## 基本

```bash
~/multi-agent-shogun/bin/notify.sh TARGET 'メッセージ'
```

**直接 tmux send-keys を使うな。notify.sh を使え。**

---

## TARGET 一覧

| TARGET | 宛先 | 用途 |
|--------|------|------|
| multiagent:0.0 | 家老 | 通常の指示 |

> 軍師・足軽への直接通知は禁止。全て家老経由。

---

## 使用例

### 家老への指示

```bash
~/multi-agent-shogun/bin/notify.sh multiagent:0.0 'queue/shogun_to_karo.yaml に新しい指示がある。確認して実行せよ。'
```

---

## 家老の状態確認

指示を送る前に、家老が処理中でないか確認：

```bash
tmux capture-pane -t multiagent:0.0 -p | tail -20
```

### 処理中のサイン
- "thinking"
- "Effecting…"
- "Esc to interrupt"

### 待機中のサイン
- "❯ "（プロンプト表示）
- "bypass permissions on"

処理中の場合は完了を待つか、急ぎなら割り込み可。

---

## 禁止パターン

```bash
# ダメ：直接 send-keys
tmux send-keys -t multiagent:0.0 'メッセージ' Enter

# ダメ：軍師への直接送信
~/multi-agent-shogun/bin/notify.sh gunshi:0 'メッセージ'
```
