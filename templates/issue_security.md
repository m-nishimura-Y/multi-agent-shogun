# セキュリティ問題 ISSUE テンプレート

## 使用方法
このテンプレートをコピーし、`{{変数}}` を実際の値に置き換えてISSUEを作成せよ。
該当しないセクションは削除してよい。

---

## ISSUE タイトル
```
🔴 [Security] {{リポジトリ名}}: {{問題の要約}}
```

## 推奨ラベル
以下から該当するものを選択（リポジトリに存在しない場合は作成または省略）:
- `security` - セキュリティ問題
- `critical` - 即時対応必須
- `high` - 優先対応
- `medium` - 通常対応
- `low` - 低優先度
- `technical-debt` - 技術的負債
- `eol` - EOL技術スタック
